# 🚀 Boostify SMM

**Boostify SMM** is a powerful and fully dynamic Social Media Marketing (SMM) panel built with Laravel. It enables you to sell or resell social media services such as followers, likes, views, and traffic across major platforms.

Whether you're running your own SMM business or acting as a reseller via API providers, Boostify SMM provides everything you need to manage services, orders, users, and payments efficiently.

---

## ✨ Features

- Fully dynamic admin panel
- Create and manage unlimited services & categories
- API integration with third-party SMM providers
- User-friendly ordering system
- Multi-payment gateway support (PayPal, Stripe)
- Multi-language support
- SEO & content management tools
- Ticketing & support system
- Announcement & FAQ management

## ⚙️ Requirements

Ensure your server meets the following requirements:

- Server: Apache / Nginx  
- PHP: >= 7.3  
- MySQL database  
- PHP Extensions:
  - cURL
  - OpenSSL
  - PDO
  - Mbstring
  - XML
  - Tokenizer
  - JSON
  - Ctype
  - BCMath
  - Fileinfo
  - ZIP
- `allow_url_fopen` enabled  
- Mod Rewrite enabled
